# Expense Tracker

A client-only, single-user expense tracker built with React and TypeScript. Work in progress.

## Stack

React, TypeScript (strict), Vite, Tailwind CSS, Vitest and Testing Library. Deployed on Vercel. No backend.

## Getting started

Requires Node 22.22.2+, 24.15+ or 26+.

```sh
npm install
npm run dev
```

## Scripts

| Command                | What it does                                 |
| ---------------------- | -------------------------------------------- |
| `npm run dev`          | Start the dev server                         |
| `npm run build`        | Typecheck and build to `dist/`               |
| `npm run preview`      | Serve the production build                   |
| `npm run lint`         | Run ESLint                                   |
| `npm run typecheck`    | Run the TypeScript compiler                  |
| `npm run test`         | Run the unit tests once                      |
| `npm run test:tz`      | Run the tests in Singapore and New York time |
| `npm run format`       | Format the code with Prettier                |
| `npm run format:check` | Check formatting without writing             |
